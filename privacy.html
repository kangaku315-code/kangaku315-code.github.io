AI秘書 プライバシーポリシー

最終更新日：2026年11月19日

1. 対象

AI秘書（以下「本アプリ」）は、運営者本人が個人で使うためのアプリです。本アプリが扱うのは、運営者本人のGoogleアカウントのデータだけです。

2. 取得する情報

本アプリは、Google APIを通じて次の情報にアクセスします。

  • Googleカレンダーの予定（閲覧・作成・変更・削除）
  • Gmailのメール（閲覧・ラベル変更・下書き作成・送信）
  • Google ToDoリストのタスク（閲覧・作成・変更）

3. 利用目的

取得した情報は、運営者本人がLINEで出した指示に応えるため、また予定・メール・タスクの通知を本人に届けるためだけに使います。

4. 第三者への提供

取得した情報を販売したり、広告に使ったりすることはありません。指示の内容を理解して返答を作るため、必要な範囲の情報をAnthropic社のAI（Claude API）とLINEヤフー社のLINE Messaging APIに送ります。それ以外の第三者には提供しません。

5. 保存

Googleの認証情報は、運営者本人だけが管理するサーバーと設定画面に保存します。メールや予定の内容を本アプリが恒久的に保存することはありません。

6. Google API Services User Data Policy への準拠

本アプリがGoogle APIから受け取った情報の利用と他アプリへの転送は、Limited Use 要件を含む Google API Services User Data Policy に従います。

7. 連携の解除

Googleアカウントの「サードパーティのアクセス」から、いつでも本アプリへのアクセス権を取り消せます。
